# Example 01 - renewal increase

One complete worked run, shipped so an agency can see the flow before risking a
real mailing. Holds `LETTER.md` (the input), `reactions/` (the seat reactions),
`SYNTHESIS.md`, `SCORECARD.md`, and `RESULT.md`.

This is a see-the-flow layer, never the verification. The kit refuses to run
against it; verification happens on the agency's own letter.
