# references

The standards the skill reads while working - prose rules, not executable code.

Reused from the proven panel: `panel-standard.md`, `dossier-standard.md`,
`synthesis-and-scoring.md`, `calibration-standard.md`, `runtime-execution.md`.
New and insurance-specific: `book-seat-shapes.md` (the thirteen policyholder
shapes), `letter-input-standard.md` (the input rules in prose),
`seat-protocol.md`, and `safety-and-honesty.md` (the insurance boundaries).

They are also the fallback when a harness cannot execute scripts: the gate and
the validators become rules applied by hand from these files.
