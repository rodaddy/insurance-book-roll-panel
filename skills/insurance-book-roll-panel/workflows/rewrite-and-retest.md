# Rewrite and Retest

Start from a completed, validated run. Read
`references/synthesis-and-scoring.md`, `references/letter-input-standard.md`,
and `references/safety-and-honesty.md`.

The agency stays the author. This produces three versions for a person to choose
between and does not send anything.

## 1. Diagnose before rewriting

Separate:

- objections raised by several core seats — these drive the rewrite;
- one credible seat raising a high-consequence objection, especially the
  compliance-and-claims reviewer, which must be fixed regardless of frequency;
- the hard-no's rejection, which is NOT a problem to solve — that client was
  leaving before the letter arrived, and rewriting toward them costs the seats
  who were staying;
- the wrong-fit seat's reaction, which is only a problem if it turned positive;
- what no letter can fix. A 22 percent increase is a 22 percent increase.
  Wording changes whether the client calls before shopping; it does not change
  the number. Say so plainly rather than implying better copy solves it.

## 2. Write three genuinely different versions

Not synonym swaps:

1. **The smallest correction** — the original letter with the named defects
   fixed and nothing else touched. Often this is the one that ships.
2. **A different frame** — usually leading with the reason or the reshop the
   agency already did, rather than with the number.
3. **A different structure or ask** — a changed order, a changed call to
   action, or a different next step for the client who is interested but not
   ready.

Every claim in every version comes from `owner/OWNER-CONTEXT.md` § What is true
and provable. Nothing in the § What must not be claimed list appears in any
version. Use the agency's voice without turning it into parody.

Keep the positioning honest in cross-sell and book-roll letters: the letter
serves the client's situation, and language that treats the client as a target
to be extracted from is the thing the panel will catch anyway.

## 3. Retest cleanly

Prepare a fresh run for each version against the SAME panel snapshot, the same
weights, and the same execution mode. Do not tell the seats a previous version
existed, what it scored, or which one the agency prefers.

## 4. Compare

Report score movement, changed decisions by core seat, whether the dissent seats
stayed honest, and what objections survived all three. Prefer a version because
the evidence improved, not because its number is larger — a version that wins on
score while flipping the wrong-fit seat to yes is worse than the one it beat.

Stop after three unsuccessful cycles. At that point the problem is the offer,
the number, or the timing rather than the words, and the honest recommendation
is to say so and to go ask real clients.
