# workflows

The procedures the skill follows, one file per thing the agency asks for.

`build-book-panel.md` builds the thirteen seats from the agency's book;
`wash-letter.md` reads a letter through them; `rewrite-and-retest.md` produces
and retests three versions; `calibrate-panel.md` records what actually happened
after the mailing; `maintain-panel.md` and `room-lifecycle.md` cover upkeep and
resetting a room between letters.

`build-book-panel.md` and `wash-letter.md` each carry the refusal conditions.
