# Start Here

You have a zip file. Here is how to get it in front of your AI, on whatever
device you are holding.

## iPhone or iPad

1. Open the **Files** app and find the zip where you saved it (usually
   **Downloads**).
2. **Tap the zip once.** It unzips itself into a folder with the same name.
3. Open that folder and touch and hold **installer.md**.
4. Choose **Share**, then pick your AI app (Claude or ChatGPT).
   If sharing into the app does not work, tap the file to open it, select all
   the text, copy it, and paste it into a new chat instead.

## Windows

1. Find the zip in your **Downloads** folder.
2. **Right-click it, choose Extract All, then Extract.** A folder opens.
3. Open your AI in the browser (Claude or ChatGPT) and start a new chat.
4. **Drag installer.md from that folder into the chat box.**

## Mac

1. Find the zip in your **Downloads** folder.
2. **Double-click it.** A folder appears next to it.
3. Open your AI (Claude or ChatGPT) and start a new chat.
4. **Drag installer.md from that folder into the chat box.**
